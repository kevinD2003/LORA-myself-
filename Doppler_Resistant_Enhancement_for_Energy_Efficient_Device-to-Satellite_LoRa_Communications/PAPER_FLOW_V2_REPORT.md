# Dietl 论文逐符号流程在 V4 帧上的修订与效果

> 历史消融：本版本沿用21点质心，并使用 V4 已知 midamble。针对论文所述
> “centroid size 10”的后续代码核查见 `PAPER_10POINT_ALIGNMENT_REPORT.md`；
> -21 dB 的论文原生无额外导频移植结论以10点、无 midamble 分支为准。

日期：2026-09-26。正式产物：`results/project_paper_flow_v2/`。

## 修订的流程

原移植只从8个前导和112个数据符号取质心，在物理时间轴上跳过37个已经发送的
midamble。新接收机依次处理 V4 帧的全部157个物理符号：

1. 每个符号使用相同 Hann 窗、4倍零填充 FFT 与峰值质心估计。
2. 前8个已知 upchirp 按论文式(18)形成初始偏移，最小二乘拟合式(19)(20)。
3. 对数据符号，以此前最近8个物理符号的偏移预测，按式(21)硬判决，并按式(22)
   记录本次偏移；当前判决只能影响后面的符号。
4. 对 V4 帧中已知的零符号 midamble，直接用已知标签计算偏移，纳入后续的
   最近8符号历史。Fixed LR 的回归系数仍只由最初的前导决定。

当输入帧没有 midamble 时，新核心与旧 Eq. (18)-(22) 解码器逐符号一致。
midamble 原本就在三方法共同接收的 V4 帧中，本次没有再增加发送符号；但它
确实使用了 V4 已有的导频开销，因此应称为“V4 已知 midamble 适配版”，不能
冒充论文的无额外导频开销性能。

## 同帧1000包正式结果

两个场景各有 -30 至 -21 dB 的10档 SNR，每格1000包。下表为 Adaptive LR
的代表点；完整的七方法140行 CSV 含每格的 SER、hard BER 和逐包配对95%
bootstrap 区间。

| 场景 | SNR | 旧移植 SER | 新流程 SER | 旧移植 hard BER | 新流程 hard BER | SER 降低的95%区间 |
|---|---:|---:|---:|---:|---:|---:|
| 高频移 | -24 dB | 0.9948 | 0.9973 | 0.4877 | 0.4789 | [-0.0041, -0.0011] |
| 高频移 | -22 dB | 0.8179 | 0.7265 | 0.2587 | 0.2465 | [0.0732, 0.1088] |
| 高频移 | -21 dB | 0.5783 | 0.3009 | 0.1182 | 0.0701 | [0.2532, 0.3022] |
| 高变化率 | -24 dB | 0.9941 | 0.9970 | 0.4850 | 0.4792 | [-0.0044, -0.0016] |
| 高变化率 | -22 dB | 0.8138 | 0.7535 | 0.2630 | 0.2589 | [0.0447, 0.0785] |
| 高变化率 | -21 dB | 0.5841 | 0.3033 | 0.1160 | 0.0702 | [0.2570, 0.3045] |

因此，-21 dB 两场景的 SER 分别降低约27.7和28.1个百分点；-22 dB
降低约9.1和6.0个百分点。-24 dB 的 SER 反而略差，低于该 SNR 时两版
几乎都失锁。Fixed LR 在新旧两版中数值完全相同，符合其前导后冻结回归的
定义。项目 Stage55 在高变化率 -21 dB 仍有 SER 0.0163，显著低于新流程
的0.3033。

## 验证边界

- 全部20,000帧的接收 IQ 指纹与原 V23 正式结果一致；旧五方法逐包错误数
  原样保留。
- 新接收机接口不接收 payload 真值或轨道真值；已知 midamble 来自帧结构。
- 论文仅写“centroid size 10”，未说明是否指总点数或峰值两侧各10点；
  此处沿用此前记录的两侧各10点假设，以便单独识别流程修订的效果。
- 论文原生帧没有本项目的37个 midamble，不能把适配版结果作为论文作者
  原始无额外开销算法在 V4 条件下的唯一结果。
