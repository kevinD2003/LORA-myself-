# SF11 校准复现说明

## 定位

本实验用于连接已完成的 SF7/SF12 校准接收机与后续 Stage55 同条件移植。
论文没有给出 SF11 的 Figure 10/11 曲线，因此本实验不针对 SF11 图像反向调参。

原始 `paperSf11Config` 及其结果保持冻结。新增配置和结果均标记
`fittedOrTuned=true`，表示其参数来源包含 SF7/SF12 图像校准。

## 参数来源

- SF=11，带宽125 kHz，LDRO开启。
- Midamble间隔仍按论文式(19)-(20)推导为12个数据符号。
- Rician K、初始CFO估计、残差估计和更新时延继承SF7/SF12共同校准机制。
- SF11没有论文目标曲线且将作为Stage55桥梁，因此Doppler时间尺度恢复为物理值1，
  不继承SF12图像校准使用的0.5。
- Midamble估计损失由SF7的0.50 dB和SF12的0.25 dB在dB域按SF线性
  插值，SF11取0.30 dB。
- 正式随机种子271828未用于SF7/SF12参数选择。

## 验收原则

由于不存在论文SF11目标曲线，本实验只检查可解释的算法机制：

1. Case 1中Point的SER不高于Midamble-Point。
2. Case 2中Midamble-Point的SER严格低于Point。
3. 每个SNR点使用5000包，SER必须等于原始错误数除以数据符号总数。
4. 不交换、平移、缩放或平滑曲线。
5. 原始SF11结果和主项目哈希不得改变。

通过上述验收后，才能把接收机机制移植到Stage55公共物理账本；Stage55的
信道、轨道、编码、SNR、payload和随机种子不能从本实验复制过去。

## 正式结果

每个SNR点均使用5000包。最高SNR -18 dB的结果如下：

| 场景 | 方法 | SER |
|---|---|---:|
| Case 1 | 无Doppler | 0.007300 |
| Case 1 | Point | 0.019543 |
| Case 1 | Midamble-Point | 0.020621 |
| Case 2 | 无Doppler | 0.007629 |
| Case 2 | Point | 0.332379 |
| Case 2 | Midamble-Point | 0.039036 |

Case 1的10个SNR点全部满足Point不高于Midamble-Point。Case 2的10个
SNR点全部满足Midamble-Point低于Point；在-18 dB时相对SER降低约88.3%。
