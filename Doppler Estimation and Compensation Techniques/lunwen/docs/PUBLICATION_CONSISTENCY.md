# Publication consistency and exact-match boundary

## Result

The independent implementation is internally validated, but the available
publication materials do not define one executable experiment that can also
match every final-paper number. The machine audit therefore separates:

- `state=independent_reproduction_passed`, and
- `paperMatchState=not_reproducible_from_available_publication_materials`.

It does not claim a complete point-for-point paper reproduction.

## SF12 Table 3 proof

For SF12 at 125 kHz, one chirp lasts 32.768 ms. The Point frame inferred from
the paper's rounded 1.090 s value is exactly 1.089536 s and contains 23 payload
chirps. With `n_int=3`, Eq. (20) requires

    ceil(23/3) = 8 midambles.

The realizable Midamble-Point duration is therefore

    1.089536 + 8*0.032768 = 1.351680 s.

Table 3's 1.341 s instead agrees, within its millisecond rounding, with

    1.089536 + (23/3)*0.032768 = 1.340757... s.

This calculation uses 7.666... midambles. The adjacent realizable durations
are 1.318912 s for seven pilots and 1.351680 s for eight pilots. Thus the table
value is a fractional-count approximation that conflicts with Eq. (20), not a
duration that an integer-symbol frame can attain. The executable proof is
`src/analyzePublicationConsistency.m`; its output is
`results/publication_consistency.json`.

## SER evidence

Reference [12] uses an ADC rate of 2B, two low-pass FIR filters, and then
downsamples to B before the 2^SF FFT. Its SNR definition already uses noise
power inside B. Consequently, merely generating twice as many samples does
not justify an SNR shift when the filter and noise bandwidth are normalized
consistently.

Two focused diagnostics rule out tempting undocumented substitutions:

1. Searching only the 1024 valid SF12 LDRO bins lowers the no-Doppler endpoint
   but severely worsens Case 2. At -21 dB, the 1000-packet diagnostic changes
   Midamble-Point from 0.10687 to 0.53587. The paper's 0.5B/M tolerance model
   supports retaining the fine-bin peak followed by nearest-symbol mapping.
2. Independent Rician fading at every sample is also not the missing model.
   It produces no-Doppler endpoints near 0.000061 (SF7) and 0.000696 (SF12),
   far below the paper plots as well as the packet-flat results.

The raw diagnostic counts are in `results/diagnostics`. Neither diagnostic is
selected as the production profile, and neither uses paper endpoints as input.

## Frozen-result preservation

The six authoritative SF7/SF11/SF12 CSV files were not regenerated by this
audit change. Their SHA-256 digests are frozen in
`reference/primaryResultHashes.csv` and verified on every top-level audit.
An additional regression test runs the explicit `peak_quantize` LDRO setting
and the pre-change missing-field default under identical seeds for both cases
and all three delivered strategies; their error counts must be identical.

## Version conflict

The public arXiv source says AWGN-only and uses SF12 `n_int=1`. The final IEEE
paper says Rician K=10 dB and uses SF12 `n_int=3`. The public EPS files were
generated separately, but the final extended simulator and its temporal
Rician, filtering, and synchronization settings were not supplied. Those two
profiles remain separate in this repository.

An exact final-paper numerical match can be evaluated without reverse tuning
when the authors' final simulator, raw curve data, or a complete channel and
receiver parameterization becomes available.
