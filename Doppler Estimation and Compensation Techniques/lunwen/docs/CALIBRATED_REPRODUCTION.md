# Calibrated Figure 10/11 reproduction

## Scope

This profile was explicitly fitted to the frozen endpoint bands digitized from
the final paper. It is intended to make the simulated curves as close as
practical to Figures 10 and 11; it is not evidence that the unpublished author
simulator used these values.

The independent profile and all six primary CSV files remain unchanged.

## Selected parameters

- Effective Rician K factor: 12.75 dB instead of the stated 10 dB.
- CFO estimator FFT zero-padding factor: 4 instead of the locked native FFT.
- Midamble residual estimator: native FFT. The residual is already close to
  zero, so applying sub-bin refinement there tracks noise rather than the
  large initial carrier offset.
- Midamble update pipeline latency: one data symbol, representing dechirping,
  FFT peak detection, and estimate-update processing before the new estimate
  becomes available. The independent idealized profile retains zero latency.
- Embedded-Midamble estimator implementation loss: 0.5 dB for SF7 and
  0.25 dB for SF12. The shorter SF7 observation receives less frequency-
  estimation processing gain. The loss is applied only while estimating the
  residual from a pilot, not to payload detection.
- Within-frame Doppler time scale: 0.5 instead of the published orbit model's
  unscaled local time.
- Final validation seed: 314159, not used in either search stage.
- Point and Midamble-Point use paired channel and payload-noise realizations;
  only Midamble-Point consumes the additional pilot-noise realizations.

All calibrated outputs carry `fittedOrTuned=true` and are written only below
`results/calibrated`.

## Algorithmic corrections

The final curves are regenerated by receiver/channel code; no curve is
swapped, vertically shifted, smoothed, or overwritten with paper pixels.

1. Initial Point CFO and Midamble residual CFO use separate estimator stages.
   The initial approximately 20 kHz offset uses a four-times zero-padded FFT;
   the near-zero residual uses the native FFT grid to avoid tracking sub-bin
   noise.
2. A one-data-symbol update pipeline models the time required for Midamble
   dechirping, FFT peak detection, and state update.
3. The embedded pilot estimator includes the SF-dependent implementation loss
   stated above; payload detection SNR is unchanged.
4. Point and Midamble-Point use paired channel and payload-noise realizations.
   This removes artificial crossings caused by independent Monte Carlo draws;
   only Midamble-Point consumes additional pilot-noise samples.

The project audit recomputes every calibrated SER as
`symbolErrors/totalSymbols` and verifies the paper ordering at all 40 plotted
SNR comparisons. Therefore a manually reordered or edited curve fails audit.

## Selection and validation

The first search evaluated K in {11, 12, 13} dB and FFT padding in {1, 4, 16}
using seed 2025 and 256 packets per endpoint. K=12 dB with padding 4 matched
11 of 12 endpoint bands. A Doppler-scale search then found several 12/12
candidates. A second seed (92026) was used to stabilize K, selecting 12.75 dB.

The final held-out validation used seed 314159 and 5000 packets per endpoint.
All 12 endpoints fell inside the frozen paper bands. The authoritative held-out
counts are in
`results/calibrated/validation/calibrated_endpoint_validation.csv`.

The complete curve files use 1000 packets per interior SNR point. Their final
endpoint rows are replaced by the higher-precision 5000-packet held-out runs
from the same calibrated profile. Run simulation and rendering in separate
MATLAB processes with `runCalibratedReproduction.m` followed by
`renderCalibratedFigures.m`; this avoids a MATLAB R2022a graphics teardown
failure observed after a long FFT simulation.
