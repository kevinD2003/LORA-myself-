## 发现与建议

1. **Stage55 测试入口有既有 R2022a 兼容错误。** `stage55ProjectTestSuite.m:8` 的参数默认值调用嵌套函数，R2022a 拒绝构建套件，因此 Stage55 / 全项目回归入口未验证通过。该源码与整理前 SHA-256 完全相同。建议单独修复套件构造器，再运行完整回归。
2. **三张学习文档历史配图在整理前已缺失。** Stage1 轨迹、分段近似图及 Stage18 置信质量图。学习文档已明确缺失；Stage45 原图仍存在。详情见 [缺失引用](preexisting_missing_links.csv)。需要时另建结果目录重跑对应实验。
3. **Stage26 排队脚本不能在本机直接复用。** 硬编码的 `E:/Matlab2022/MATLAB2022/bin/matlab.exe`、`results/stage26_formal_ber` 当前不存在，等待 PID 为历史值。脚本内容原样保留，维护说明已标注限制。
4. **版本的验收状态不同。** Unified V23 原报告为 PASS / ADMIT_V23_FREEZE；V19/V21/V22 是历史 FAIL，结果索引已单列。历史通过状态不能代替当前验证。
5. **34 组 / 71 个 MATLAB 文件内容完全相同。** 主要属于独立实验或冻结来源副本，涉及不同依赖和溯源，保持各自位置；见 [相同源码记录](identical_source_groups.json)。
6. **旧文档仍包含历史方案、备份和旧结果的记录。** 新 README 及导航仅链接现存入口。组会构建脚本依赖另一个项目的结果及指定版本呈现工具；原 PPTX 保持原样。
