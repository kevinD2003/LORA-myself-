# 全曲线逐符号版本验证

本目录是独立实验，不覆盖既有算法、已冻结结果和其他项目。先运行每点 100 包的 `validation100`；独立 1000 包队列使用不同种子，须通过完整性检查后才能启动。

覆盖 SF7/SF12 × AWGN/Rician：Case1、Case2 各 10 个 SNR 点，半轨各 5 个时刻，共 100 个物理点。每个点均计算 PREC、V8 Symbol-VP / Rolling-N8、复现论文方法，以及原生帧/论文导频帧各自的理想条件。主 SER 是译码前 FFT 硬判决 chirp 错误，分母为包数 × 112；硬 FEC 后信息位 BER 单独报告。

| 条件             | SF7       | SF12       |
| -------------- | --------- | ---------- |
| Case SNR/复采样   | −15:−6 dB | −30:−21 dB |
| 论文 AWGN 对应端点   | −7 dB     | −22 dB     |
| 论文 Rician 对应端点 | −6 dB     | −21 dB     |
| 数据 chirp / 信息位 | 112 / 448 | 112 / 768  |
| 论文方法导频间隔       | 12        | 3          |
| 原生帧 / 导频帧物理行   | 120 / 129 | 120 / 157  |

两种 SF 都保留 CR3、完整字母表、无 LDRO、8 个上 chirp 前导；PREC/VP 帧无显式 midamble。Case1/2 起点为 −366/0 秒。半轨点为 −366、−274.5、−183、−91.5、0 秒；AWGN 的 Es/N0=14 dB，Rician 为 15 dB。采样 SNR 按 `Es/N0 − 10log10(2^SF)` 计算。

Rician 固定 K=10 dB、平均总功率 1：LOS 功率 10/11，四个独立复高斯散射抽头各 1/44，延迟 8/16/24/32 微秒。抽头在包内固定，所有方法共用同一 PDP 和对应抽头；噪声方差为 `10^(-SNR/10)`，不按单包接收功率归一化。这是本项目采用的多径假设，不能声称是论文给出的原始 PDP。

原生帧与导频帧分别按实际时间生成，再经过跨 chirp 的因果串行卷积；共享载荷、抽头和按语义索引配对的数据/前导噪声。理想条件仅离线去除共同多普勒相位，保留衰落、ISI 和旋转后的噪声。实际接收机只接收样本和帧布局，PREC 使用前导估计的噪声功率。

## 运行与证据

在 MATLAB 中先运行 `acExportPlan`；PowerShell 入口为 `launchAcValidation.ps1 -Cohort validation100 -Workers 4`。每点每 5 包断点保存，记录原始硬判决、逐包错误、失败、种子、运行时间和 VP 诊断。失败接收机计入全部 112 个 chirp 错误，不丢弃包。断点身份与数值代码、配置和种子绑定。

汇总/绘图见 `analysis/README.md`。`ENDPOINT_24_COMPARISON.csv` 只在论文相同横坐标比较复现方法/理想条件，共 24 行；不会用本项目更右侧的 AWGN 点替代论文端点。名义 SER 比较和逐点单侧 95% 比较分开；100 包结果是初验，零次错误不能证明真实 SER 为零，也不能证明同时满足全部 24 点。

`VALIDATION_GATE.json` 仅表示全 100 点各 100 包、源码一致且运行/译码无失败。论文阈值和方法排序不作为完整性门限，不通过调参强制排序。最终结论还须读取端点比较表和置信区间。

## 解释结果时的边界

CR3 的纠错冗余改善的是译码后 BER/FER。在相同采样 SNR、SF 和译码前硬 FFT chirp SER 口径下，不能直接推出 CR3 必须优于 CR1。VP 内部使用编码信息辅助估计，但最终 SER 仍取原始硬判决，不用重编码标签替代。

逐符号补偿表示为每个数据 chirp 计算并应用补偿。原始 V8 的额外 rate 更新有可观测性门限；干净夹具中 SF7/SF12 均可出现零次额外 rate 更新，同时 CFO 逐符号反馈仍工作。此实验保留原门限。PREC 在中心动态场景使用固定 CFO、零 rate 补偿，SF12 较长包可能出现高 SER；已用原函数直接重放确认，不据此修改算法。
