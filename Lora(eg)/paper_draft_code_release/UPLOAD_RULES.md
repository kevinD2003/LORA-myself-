# 上传规则

## 上传

- MATLAB 源码、运行入口和测试。
- 必要的 JSON 参数文件和来源清单。
- 论文初稿需要的算法说明与实验定义。
- 每条曲线的独立入口文件。

## 不上传

- 冻结结果、正式结果、历史结果和源码快照结果目录。
- MAT 检查点、断点续跑缓存和逐包原始计数。
- 未审计的 PNG，以及 FIG、PDF 等生成产物。
- 日志、临时文件、MATLAB 偏好和本机路径缓存。

仅 `12_Result_Figures/` 中通过完成状态、来源哈希和目视检查的 PNG 可以上传。

冻结数据仍保留在原工程，不移动、不删除。已复制源码和发布图分别由每个工程的 `source_files_sha256.csv` 与 `figure_files_sha256.csv` 记录并核对。
