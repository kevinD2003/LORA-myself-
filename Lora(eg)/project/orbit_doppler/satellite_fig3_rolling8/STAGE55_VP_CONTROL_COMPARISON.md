# Stage55 虚拟导频严格控制变量对照

更新时间：2026-08-11

## 1. 这项对照回答什么问题

本实验只回答一个问题：在 Stage55 接收机中，开启虚拟导频本身是否带来收益。

每个轨道帧只生成一次接收信号，然后将完全相同的信号分别送入：

- `Stage55-NoVP`：关闭载荷虚拟导频；
- `Stage55-VP`：开启原 Stage55 虚拟导频。

两条路径共享同一噪声、真实轨道多普勒、前导码估计、跨帧初始状态、初始频偏变化率、补偿公式、Hamming 译码方式和统计帧。唯一变化量是 `EnableVirtualPilots`。因此，这组结果可以用于说明虚拟导频的独立贡献；原来的 Huang 硬解调对照仍然是系统级对照，不能单独用于证明虚拟导频的贡献。

## 2. 指标和区域

- 主指标：载荷符号错误率（SER）。它最直接反映逐符号频偏补偿是否改善 LoRa 符号判决。
- 机理指标：载荷逐符号频偏估计 RMSE，单位为 FFT bin。
- 辅助指标：硬 Hamming BER、最终 ML 软 Hamming BER、PER 和有效吞吐量。
- 高频偏变化率区：每帧频偏漂移不小于 `0.5 bin/frame`。
- 高绝对频偏区：每帧频偏漂移小于 `0.5 bin/frame`，但位于可见窗口两端的高绝对频偏段。

PER 只要一帧中残留一个比特错误就记为整帧失败，在低信噪比时容易饱和，因此不替代 SER，只作为最终业务层结果保留。

## 3. 完整轨道 1-pass 基线结果

本次运行使用 `SNR = -21/-20 dB`，每个 SNR 一次完整可见轨道，共 864 个配对帧。它用于确认趋势和接线，不作为 95% 统计显著性结论。

| SNR | 区域 | NoVP SER | VP SER | VP 相对变化 | NoVP CFO RMSE | VP CFO RMSE | NoVP/VP 软 BER | NoVP/VP PER |
|---:|---|---:|---:|---:|---:|---:|---:|---:|
| -21 dB | 高频偏变化率 | 0.047360 | 0.048072 | 增加 1.50% | 0.059545 | 0.066770 | 0.001215 / 0.001513 | 0.15217 / 0.14493 |
| -21 dB | 高绝对频偏 | 0.048439 | 0.049107 | 增加 1.38% | 0.059074 | 0.061767 | 0.001121 / 0.001203 | 0.12925 / 0.13946 |
| -20 dB | 高频偏变化率 | 0.010158 | 0.010675 | 增加 5.10% | 0.053883 | 0.061719 | 0 / 0 | 0 / 0 |
| -20 dB | 高绝对频偏 | 0.009536 | 0.009900 | 增加 3.82% | 0.052324 | 0.061324 | 3.865e-5 / 2.416e-5 | 0.006803 / 0.003401 |

审计结果：

- 四组中平均接纳虚拟导频为 `3.30--7.15 个/帧`；
- 受至少一个新虚拟导频影响的符号覆盖率为 `53.4%--76.2%`；
- 四组误接纳虚拟导频均为 0；
- 当某帧没有接纳虚拟导频时，NoVP 与 VP 的 SER 和 CFO 结果逐项完全相同。

## 4. 当前能得出的结论

当前 Stage55 的虚拟导频不能被表述为“普遍优于无虚拟导频”。在这次严格消融中，四个区域的原始 SER 都轻微升高，CFO RMSE 也都升高；只有部分区域在最终软译码后表现出 PER 或软 BER 改善。

这说明问题不只是“虚拟导频数量少”。少量接纳仍可通过 rolling 历史影响一半以上载荷符号，但在低信噪比下，虚拟导频的符号标签即使判对，其细频偏测量仍可能比跨帧前导码状态更嘈杂。当前算法会让这些载荷观测逐步替换前导码观测，因此可能扰动已经较准确的补偿轨迹。

所以，已有 Huang 硬解调与 Stage55 的明显差距不能全部归因于虚拟导频；其中还包含跨帧前导码状态、动态频偏跟踪和 ML 软译码等共同变化。论文中应把 Huang 对照写成“系统级对照”，把本实验写成“虚拟导频消融对照”。

## 5. 文件与复现

主入口：`run_stage55_vp_control_comparison.m`

1-pass 结果目录：`results/stage55_vp_control_comparison`

主要输出：

- `stage55_vp_control_region_summary.csv`：两种区域的总 SER、BER、PER、CFO RMSE 和覆盖率；
- `stage55_vp_control_window_statistics.csv`：10 秒轨道窗口统计及 95% 二项区间；
- `stage55_vp_control_symbol_position_ser.csv`：112 个载荷符号位置的 SER；
- `stage55_vp_control_block_position_ser.csv`：16 个 Hamming 码块位置的 SER；
- `stage55_vp_control_frame_records.csv`：逐帧配对原始统计；
- `stage55_vp_control_comparison.mat`：完整 MATLAB 数据。

在 MATLAB 中运行一次完整基线：

```matlab
run_stage55_vp_control_comparison
```

论文统计建议至少运行 5 次独立完整轨道，并写入新目录：

```matlab
run_stage55_vp_control_comparison( ...
    PassCount=5, ...
    OutputFolderName='stage55_vp_control_comparison_5pass')
```

不得根据结果重新挑选 seed 或只保留有利区域。下一步若优化虚拟导频，应优先研究观测不确定度加权、保留前导码锚点和更严格的残差质量门限，而不是只放宽门限来增加数量。
