# Stage55 改进后项目：全新重跑三方法结果

本报告不读取旧的冻结性能数据。NoVP、VP-quality 和 Huang-PREC-CP 均使用本轮重新生成的同一批载荷、噪声与连续相位波形。

- SNR：[-21 -20] dB
- 独立遍历次数：3
- 载荷种子基数：2026551800
- 噪声种子基数：2026551900
- 每帧有效载荷：704 bit；帧时长 0.983040 s

`Stage55-NoVP` 与 `Stage55-VP-quality` 的唯一处理变量是是否允许可靠载荷判决进入虚拟导频跟踪。两者都使用 ML-soft Hamming 输出。`Huang-PREC-CP` 按黄鹏论文式 (4-1)--(4-7) 搜索 eta/CFO，为与 Stage55 的连续相位波形公平比较，对各前导 FFT 功率求和，且载荷期 CFO 保持冻结。三路 delivered BER 均使用同一 ML-soft Hamming 引擎；hard BER 是不含软译码差异的主公平指标。
