# Stage55 改进后项目：全新重跑三方法结果

本报告不读取旧的冻结性能数据。NoVP、VP-quality 和师兄原始 PREC 均使用本轮重新生成的同一批载荷、噪声与连续相位波形。

- SNR：[-21 -20] dB
- 独立遍历次数：3
- 载荷种子基数：2026551800
- 噪声种子基数：2026551900
- 每帧有效载荷：704 bit；帧时长 0.983040 s

`Stage55-NoVP` 与 `Stage55-VP-quality` 的唯一处理变量是是否允许可靠载荷判决进入虚拟导频跟踪。两者都使用 ML-soft Hamming 输出。`Senior-PREC` 是外部参考，使用师兄代码的一帧一次前导 CFO 与硬 Hamming，因此“delivered BER/PER”不是纯粹的虚拟导频消融；请同时查看 hard BER。
