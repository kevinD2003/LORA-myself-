# 临时论文检查材料

论文阅读截图位于 [pdfs](pdfs/README.md)，按用途分类：

- `paper_pages/`：论文单页截图。
- `figure_crops/`：Figure 10/11 局部裁剪。
- `theory_channel/`：理论与信道条件核对。
- `midamble/`：Midamble 说明页。
- `doppler_paper/`：多普勒论文页面。
- `paper_fig11/`：Figure 11 相关页面。
- `case_condition_check/`：Case 条件核对。

这些文件是辅助阅读图，不能当作 MATLAB 仿真结果。实验自己的临时目录仍保留在所属实验下。
