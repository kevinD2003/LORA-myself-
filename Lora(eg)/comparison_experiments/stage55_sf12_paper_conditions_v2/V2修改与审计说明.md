# SF12 对比实验 V2 修改与审计说明

## 版本边界

- V1：`stage55_sf12_paper_conditions`
- V2：`stage55_sf12_paper_conditions_v2`

V1 源码、检查点、CSV 和图片保持不变。V2 使用独立配置、测试和结果目录，
不得载入或续跑 V1 检查点。

## V1 审计定位的问题

1. 虚拟导频验证使用旧创新门限，验证结束后才写入更窄的新门限；
2. V1 标定只检查 Case1，没有覆盖 Case2 高 Doppler 变化率；
3. 静态纯音误差被直接当成动态创新门限，未覆盖数据符号间最大时间间隔；
4. 残差估计器已经输出 peak ratio，但 Stage55 门控没有使用；
5. 正式结果只累计总体 CFO SSE，无法生成真正的逐符号 CFO RMSE；
6. 没有保存逐包配对错误数，无法计算包级配对置信区间；
7. 自动测试没有覆盖 Case2 高速率加噪声下的错误分支锁定。

## V2 最小修正

1. 先测量 CFO 误差，再根据物理速率、最大数据间隔和测量误差确定最终门限；
2. 使用最终门限分别验证 Case1 和 Case2，通过后才冻结 manifest；
3. 记录残差 peak ratio 供审计，但不直接套用 FFT 判决的 `1.05` 门限；
4. 保留原固定增益、单符号因果更新、无跨帧状态和无轨道先验；
5. 保存逐符号错误/CFO SSE、逐符号 VP 接纳数和逐包错误数；
6. Figure C 改为 5000 包逐符号 CFO RMSE；
7. 新增包级配对 bootstrap SER 差值表；
8. 新增 Case2 无噪声和加噪声分支锁定回归测试；
9. 检查点恢复时强制验证完整冻结配置一致。

残差搜索采用 `0.05 bin` 细网格，相邻候选的投影值天然非常接近。验证表明把
FFT 第一峰/第二峰门限 `1.05` 原样用于残差候选会拒绝全部 VP，因此 V2 不引入
这一未经重新定义的门控指标。

检查点配置比较只忽略 manifest 的时间戳和测量记录等非仿真元数据；物理参数、
接收机参数、随机种子或 Monte Carlo 配置发生任何变化时仍会拒绝续跑。

## 明确不加入的功能

V2 不加入以下内容，避免超出本实验目的：

- CR3/Hamming 软译码；
- 原始 112 符号 Stage55 帧；
- 跨帧 rolling-8 状态；
- 轨道真值或轨道速率先验；
- Kalman/PLL；
- Stage55 使用显式 Midamble；
- 根据正式 SER 反向调节参数。
