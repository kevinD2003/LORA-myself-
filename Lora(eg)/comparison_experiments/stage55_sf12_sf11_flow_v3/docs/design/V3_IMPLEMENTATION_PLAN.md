## 每阶段执行协议

1. 实施前核对该阶段输入、禁止项和允许修改路径。
2. 只修改 V3 目录，且只实现当前阶段所需内容。
3. 运行该阶段的确定性测试和静态审计。
4. 在 `results/reports` 写阶段审计证据；失败则停止进入下一阶段。
5. 参数、代码或种子签名变化时拒绝复用旧检查点。

## 固定物理与编码身份

- `physicalSf=12`
- `effectiveDataSf=10`
- `dataAlphabetSize=1024`
- `dataBinSpacing=4`
- `bandwidthHz=125000`
- `sampleRateHz=125000`
- `samplesPerSymbol=4096`
- `symbolDurationSec=0.032768`
- CR3 Hamming(7,4)，16 块，112 载荷符号，640 信息位
- Paper `n_int=3`
- Rician 主口径 K=10 dB，另保留 AWGN-only 机制基线
- 接收机不使用轨道真值速率先验；跨帧仅使用接收机可见的 rolling-8 前导 CFO
